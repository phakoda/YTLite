# SbWhitelistVC recovery

`SbWhitelistVC.m` reconstructs every packaged application method, with ARC generating the packaged `.cxx_destruct` ownership behavior. The iOS metadata audit verifies 18 method encodings, no properties, and the relative layout and types of `_sortButton`, `_sections`, and `_channels`. The superclass import is the canonical recovered `DVNTableViewController`; the host `YTColor +black2` dependency is declared through a class protocol and resolved by its original runtime name.

Evidence is the supplied arm package binary, SHA-256 `bdcc4d4ccaa5835d35bc97ccbdfc1c3dff514cb7161848265dcc0585f364c0ca`. `manifest.json` records every method's address and encoding, the hash of the original instruction interval, recovered branch tables, and decoded CFString values. Neither the dylib nor the input packages were modified or executed.

The sort preference uses the full signed 64-bit integer. At `0x1d762c`, `lsr x8, x20, #63` tests the sign; `0x1d7678–0x1d767c` then bounds-checks the full unsigned value. Invalid indices use newest-first. Name sorts use `localizedStandardCompare:`, date sorts use the default comparator. The original table at `0x11b8f50` selects these descriptor factories. The empty-channel branch at `0x1d7cd0` constructs the placeholder with `FEuploads`, `nochannel`, empty key and `channelCell` identifier. Nonempty entries use `name`, `link`, and optional `pfp` data; a missing photo uses the `FElibrary` bundle image. Malformed entries and undecodable nonnil photo data retain the original dictionary-literal nil rejection.

## Verification

Run from the repository root:

```sh
python3 recovery/tools/verify_whitelist.py
```

This verifies the recorded original-byte interval and branch tables, compares 17 decoded strings, compiles with the iOS SDK and audits emitted metadata, then runs the actual reconstructed source on macOS with isolated UIKit/host doubles and UndefinedBehaviorSanitizer. The 173 checks exercise sorting (including natural numeric ordering and invalid 64-bit indices), placeholders, persisted preference operations, duplicate-link removal, actions and captures, navigation, header creation/reuse, exact constraints, dynamic color branches, fresh cell allocation, image variants, malformed preference behavior and ARC ownership release. Foundation collections, sort descriptors, URLs and isolated user defaults are real; image rendering records the real callback's UIKit calls using a real bitmap graphics context. Test fixtures do not contact URLs or load the original image.

## Reconstruction limits and integration

No unresolved application branch remains in this class. Real UIKit display and the installed YouTube host were not exercised, so these checks do not prove on-device appearance. The superclass behavior is verified by its own module; this fixture replaces only its inherited table initialization. Compiler obfuscation, opaque string initialization and the binary's injected supervisor-call instrumentation are not reproduced as source. The original ownership pattern is preserved, including menu action blocks retaining the controller.

Add `recovery/source/Whitelist/SbWhitelistVC.m` to the recovered source list and import `SbWhitelistVC.h` wherever a typed settings navigation reference is needed. The class uses existing `YTLUserDefaults`, `NSBundle+YTLite`, `DVNTableViewController`, `YTPTableViewCell`, UIKit and QuartzCore. There is no additional library dependency. Parent integration owns shared source lists and reports.
