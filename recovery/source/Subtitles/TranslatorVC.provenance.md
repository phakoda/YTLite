# TranslatorVC recovery and behavioral proof

The canonical implementation covers all 15 packaged methods. This audit found no confirmed mismatch requiring a production change. The new isolated fixture executes `TranslatorVC.m` itself and closes the earlier lack of runtime proof. Its expectations come from the packaged method bodies, constants and original branch tables.

The supplied arm binary has SHA-256 `bdcc4d4ccaa5835d35bc97ccbdfc1c3dff514cb7161848265dcc0585f364c0ca`. `recovery/tests/translator_ui_evidence.json` records its complete method inventory, 24 instruction spans, 10 constant/block-descriptor records, 31 decoded strings and all 20 indirect branch decisions in the class and its callbacks. The verifier checks these against the original bytes, including the signed 32-bit branch-table adjustment, rather than executing the package or using patched analysis bytes.

Original constant records at `0xc4c2f8`, `0xc4c2f0`, `0xc4c358`, and `0xc4c238` contain double `0.9`, `0.1`, `45` and `300`. The action sentinel comparison at `0x1e3c44` is full-width `NSNotFound`; table `0x11ba918`, XOR `0xad7d5a59`, selects the update or return path. The error test at `0x1e4568` uses table `0x11ba978`, XOR `0x43e77d86`, selecting error at `0x1e459c` for nonnil error and success at `0x1e4640` for nil error.

The action and outer translation blocks use descriptors `0x1062e20` and `0x10623d0`, with copy/dispose helpers `0x150e8`/`0x15118` retaining/releasing offset 32. The queued result descriptor `0x1061910` has size 56 and helpers `0x440f4`/`0x44124`: controller, error and translation are strongly retained at offsets 32/40/48. Weak-reference tests prove the controller survives the initial completion and pending main block, and dies when the last retained block is released. Separate result/error probes confirm queued payload retention. The synchronous drawing block uses descriptor `0x10624f0`, with the symbol and double size at offsets 32 and 40.

Run `python3 recovery/tools/verify_translator_ui.py`. It checks original evidence, compiles the source for iOS and compares all 15 method encodings and nine relative ivar layouts, then compiles and executes the actual source against unique host-only UIKit, translation and dispatch doubles with UndefinedBehaviorSanitizer. The current fixture passes 384 assertions. Reports and command output are under `.recovery-work/translator-ui/`.

No packaged code, network request, preferences store or actual UI presentation runs. The fixture mocks the existing translation engine boundary; it does not claim to prove that engine, real UIKit rendering pixels, device presentation or live service behavior. Obfuscator string initialization and supervisor noise are represented by recovered constants rather than reconstructed as runtime obfuscation. No unresolved ordinary `TranslatorVC` branch was found in this audit, and no shared dependency or integration change is needed.
