# Media services hooks

`MediaServices.x` reconstructs ten replacements from the packaged primary registrar at `0x53fac`. The manifest pins each complete callback interval and the URL helper at `0xcc72c` against the original arm binary.

Cast-button updates forward only when `noCast` is false. Device-discovery and hints setters OR the incoming Boolean with the preference. The hints getter and fullscreen-exit getter return their preferences directly, without calling the previous implementation.

The share helper finds the first query item named `si`, `is`, or `pp` and removes it and every later item. It preserves earlier items and the fragment. Matching uses decoded, case-sensitive query names and has no domain restriction. Unchanged input returns the original string object. The share URL getter reads the preference before invoking the previous implementation.

`setAudioFormatConstraint:` forwards first, then checks for the `_playerView` instance variable. If present, it reads the view through KVC and calls `selectCaptions` on its ancestor controller. The original only forwards the incoming register; its source enum or pointer spelling cannot be recovered from this callback. The declaration uses `uintptr_t` to preserve all 64 bits. Original obfuscator anti-debug effects are omitted.

Run `python3 recovery/tools/verify_media_services.py`. It checks original bytes and all ten iOS callback signatures, then executes the actual Logos callbacks under UndefinedBehaviorSanitizer. The 461 checks cover forwarding order, receiver and argument identity, both preference outcomes, malformed and encoded URLs, immutable and mutable strings, and audio views with absent or nil ivars. UIKit and YouTube boundary objects are fixture doubles. This does not establish behavior in a running YouTube process.
