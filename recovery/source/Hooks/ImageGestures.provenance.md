# Image and pinch gestures

The module reconstructs the two primary registrations on `YTPlayerView` and `YTImageZoomNode`, plus animation callbacks `0xccdbc` and `0xcce50`. The manifest pins all four original function intervals to the supplied arm-package hash.

`didPinch:` at `0xb367c` forwards first, then reads the player delegate and the `pinchToFullscreenShorts` preference. A `YTShortsPlayerViewController` parent enables the remaining behavior. Scale greater than 1 hides the pivot bar unless `shortsOnlyMode` is enabled and animates the playback overlay alpha to zero over 0.3 seconds. Other scales, including NaN, select the show/alpha-one branch. Both blocks reread the overlay's actual alpha and set the shared `isOverlayShown` byte from `alpha != 0`. The code does not infer visibility from the requested alpha. A nil overlay produces false; a NaN alpha produces true. The fixture tests both cases.

The image callback at `0xb5780` reads KVC `_didLoadImage` before the `postManager` gate. Instructions `0xb5d7c` and `0xb5d80` test whether the returned object pointer is nonnil, so boxed NO still enters the enabled path. Table `0x1181a90`, key `0x1181aa0`, XOR `0xc7ecf749` selects original forwarding at `0xb61b8` or URL capture at `0xb5db0`.

The enabled branch obtains the receiver's URL only if it is an `ASNetworkImageNode`; otherwise the URL remains nil. It enumerates `supernodes.allObjects`, assigns the URL to the first description containing `id.ui.backstage.original_post`, then exits the loop. Nil URL clears the selected container's previous value. Every path forwards the original recognizer pair and returns its BOOL result. The original loop end tables at `0x1181b50` and `0x1181b68` select continuation versus next enumeration batch and exit; their keys/XOR constants are `0x1181b60`/`0x1f637d24` and `0x1181b78`/`0xda551217`. Original forwarding is visible at `0xb61b8` through `0xb6200`.

The added copiedURL property comes from `FeedNodes.x`. This module shares the existing `isOverlayShown` definition with the Shorts and navigation modules.

Run `python3 recovery/tools/verify_image_gestures.py`. It checks original bytes, both iOS callback ABIs and animation-block ABIs, then executes actual Logos replacements in 914 runtime assertions under UBSan. Fixtures capture UIKit animations and supply synthetic host classes; they exercise scale/gate combinations, deferred visibility changes, nil and NaN alpha, all URL/gate/class/result combinations, boxed NO, clearing, argument identity and original-call order. No real gestures, Photos operations or network calls occur. UIKit and real YouTube integration remain unverified on-device.
