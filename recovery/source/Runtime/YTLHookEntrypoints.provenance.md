# Recovered hook entrypoints

The packaged initializer at `0x1efd4` registers SponsorBlock playback and player-bar hooks immediately. Discord registrar `0x8540` and primary registrar `0x53fac` are passed through `_ptnRegisterBlock` at `0x233e8`. Once enabled, that queue dispatches their blocks to the main queue in registration order.

`YTLHookEntrypoints.m` preserves immediate SponsorBlock installation, then dispatches the selected Discord and primary modules to the main queue. Main modules are ordered by their first original registration; each module retains its own registration order. Some original registrations interleave between modules that target different classes. This grouping preserves overlapping replacement chains but is not an exact replay of every registrar instruction.

The existing local fork reads feature preferences directly and excludes historical account activation. Consequently, the reconstructed entrypoint does not reproduce the original account-dependent release time of queued blocks. CompatibilityVersion and SettingsBridge now install before SponsorBlock through the same entrypoint, following original initializer order. Remote controls and navigation early hooks, early configuration, native share, and the manual renderer replacement install before the deferred block executes. Configuration now has explicit early and primary groups. StartupLifecycle installs the app/startup callbacks, schedules the two-second welcome and runs the original local defaults cleanup after primary hooks. The identity predicate controls the selected immediate compatibility hooks and deferred metadata hooks. Original token/bootstrap checks and activation reminders remain omitted.

`verify_hook_entrypoints.py` executes the actual constructor with intercepted scheduling and installer boundaries. It checks the immediate calls, main-queue selection, conditional metadata phase and final defaults ordering in separate matching-identity and sideload processes. Per-module fixtures independently test the actual hook implementations. This test does not load YouTube, run account services or prove all application startup behavior.
